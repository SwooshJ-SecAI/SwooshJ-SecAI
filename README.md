## What I Build

### Security Engineering

- **Cyber Intelligence Command Center (CICC)** — Real-time threat intelligence platform that aggregates CISA KEV, NVD, EPSS, and RSS feeds, enriches and scores events against organizational technology stacks, and surfaces actionable risk
- **Compliance Automation Frameworks** — Tooling for SOC 2 Type II, ISO 27001, and HIPAA audit preparation, evidence collection, control mapping, and gap analysis
- **Vulnerability Report Summarizer** — Transforms raw scan output (Nessus, Qualys, ZAP) into executive-ready reports with CVSS scoring and MITRE ATT&CK mapping
- **ITSM Automation Pipelines** — End-to-end Freshservice integration with automated ticket creation, intelligent routing, and stakeholder notification

### AI Engineering

- **15+ Custom AI Agents** — Purpose-built agents for security operations, compliance automation, IT service management, and deep research workflows
- **Security Tool Agent Builder** — Generates vendor-specific SME agents for platforms including Splunk, Arctic Wolf, SentinelOne, Palo Alto, Darktrace, SecurityScorecard, and Microsoft Purview
- **Parallel Orchestration Systems** — Multi-agent pipelines that decompose complex tasks into concurrent sub-agents with tracked task groups

### Skills and Frameworks

- **66+ Reusable AI Skills** — Modular, production-tested skill definitions spanning security analysis, document processing, orchestration patterns, and structured learning frameworks
- **Enterprise Integration Skills** — Connectors and automation skills for Freshservice, Microsoft 365, SharePoint, and security tool APIs
